🌐 **Sitio Web en Producción:** [https://trapex-peru.vercel.app](https://trapex-peru.vercel.app)

---

## 🌟 Características Principales

1. **Hero Section con Parallax & Selector Multimedia:**
   - Fotografía de alta definición del empaque mayorista de Waype con el logo oficial de TRAPEX.
   - Pestañas interactivas para alternar entre *Waype Oficial*, *Video de Proceso en Vivo* y *Retazos de Algodón de Punto*.
   - Movimiento reactivo al desplazamiento (*scroll-linked parallax*) y perspectiva 3D al cursor.

2. **Respaldo Comercial & Autoridad:**
   * Marca con presencia y venta oficial en **Sodimac Perú**.
   * Métricas en tiempo real: +20 Años de trayectoria, +80 Toneladas mensuales, +500 Empresas atendidas.

3. **Módulo de Video y Proceso Productivo:**
   * Video del proceso industrial en bucle con controles de reproducción/audio.
   * Infografía de 4 fases: *Acopio textil, Depuración manual de metales, Costura espiral y Pesaje exacto*.

4. **Catálogo Completo con Fotografías Reales:**
   * Trapos cosidos de color (multicapa en espiral).
   * Trapos blancos finos (cero desteñido con solventes).
   * Waype paño fino (400g) y Waype cardado a granel (50 kg).
   * Algodón industrial, franelas y esponjas Don Lupillo.

5. **Cotizador Mayorista en Tiempo Real:**
   * Cálculo instantáneo según volumen (Kilos, Sacos, Toneladas) y destino (Lima / Provincias).
   * Escala automática de precios con descuento mayorista.
   * Generación de mensaje directo formateado a WhatsApp con 1 clic.

6. **Sección de Economía Circular:**
   * Canal de captación para comprar mermas textiles y retazos de corte al por mayor a talleres y fábricas de confección.

7. **Panel CRUD de Gestión de Clientes:**
   * Sistema de administración integrado para gestionar cotizaciones y prospectos.
   * Operaciones: Crear, Buscar, Filtrar por estado (*Nuevo, Contactado, Cotizado, Cerrado*), Editar, Eliminar y Exportar a CSV (Excel).
   * Botón directo de WhatsApp para contactar a cada cliente registrado.

## 💻 Instalación y Uso Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/paolo-gonzalesmoya/trapex-peru.git
cd trapex-peru

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```
